# Colophon

## Construction

Root Directory uses the Obsidian plugin [Digital Garden](https://github.com/oleeskild/Obsidian-Digital-Garden). Each page comes from a Markdown document in my Obsidian vault. 

## Structure

Root Directory is navigable by link rather than folder. This is primarily because it’s what works for me in my own Obsidian vault and I am not changing it for a site. I think it allows me greater freedom – notes can belong in multiple places rather than only under one. This prevents me from having dramatic, ontological-themed meltdowns.

## Design

Currently, I am using the theme [Amber Cathode](https://github.com/bkindler/amber-cathode) by [Björn Kindler](https://github.com/bkindler).

I may make my own theme in the future or I may not. You can find out more about that [[Notes/I tried vibe coding. I don't like it.\|here]].
