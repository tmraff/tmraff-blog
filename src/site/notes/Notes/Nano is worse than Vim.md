# Nano is worse than Vim

Nano sucks. Fuck Nano. All my homies hate Nano.

Nano works fine if you're just appending a few lines to a config file but becomes awkward the moment you want to actually edit text. What you save in time by not learning the basics of Vim, you lose in actually trying to use Nano. 

## Specific gripes

- Why does it have the commands permanently taking up space at the bottom of my screen?
- Why is `^K` cut?
    - (There is historical reasoning but still)
- HOW DO I FUCKING SELECT A PIECE OF TEXT!?
    - (`^6` or `M-A` to set the mark but boy is that a choice. Especially because no beginner is going to know what setting the mark means)

## You can use Nano if you want to...

I just don't understand why you would when Vim is right there and does everything quicker and better.
