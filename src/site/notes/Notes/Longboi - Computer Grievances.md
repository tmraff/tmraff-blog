# Computer Grievances

## 1. Do not send it as a .docx

Unless you are specifically expecting someone to edit the text content, you should probably export it as a PDF. Do not send me your policy as a Word document.

## 2. Do not make forms in Word

Word is not for making forms. Word is not for storing information like that. Word shall betray you the moment you type too much for a text box. If you are having to spam spaces to make the formatting work, you should not be doing it in Word. Send me it as a fillable PDF or through a form maker.

## 3. Do not upload every image as a .png

Does your image contain a transparent background? If not, it probably does not need to be a .png. In the majority of cases, you can export the image as a .jpg at 80% and no one will be able to tell. It takes drastically less storage space.

## 4. Do not use spreadsheets if you should be using a database

A spreadsheet is for tabular data. It is a table. If you could not draw the structure of your spreadsheet with a pencil as a table, you should probably be using a database. If you are having to enter the same information into multiple areas, you should probably be using a database. If your spreadsheet started off as tabular but has become relational, migrate it. We are no longer beholden to Microsoft Access. Baserow is a free and easy to learn software.

## 5. Do not send me a file you haven't bothered to name

It literally takes less than a minute to rename your file from `very important thing v2 final final FINAL.docx`. It may mean something to you, but everyone else has also named their files the same way and now I must trawl through my Downloads opening each file to find the thing I want to open. Literally just rename it to `date surname thing` I am begging.

## 6. Do not click 'save as' unless you want a separate file

'Save' and 'save as' are not the same thing. If you merely want to update the content of your file, you are looking for 'save'. If you choose 'save as', it will create a new version of the file you are currently using and you will have to give it a unique name. 'Save as' is also used to create a version of the current file in a different editable file format.

## 7. Do not use caps lock for single capitals

Shift is a modifier key, which means that holding it changes the behaviour of the other keys you press. If you hold shift and press an alphabet key, it will give you the uppercase variant of that letter. It takes less key presses than toggling caps lock on and off for a single character.
